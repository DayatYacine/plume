## About

Plume is a lightweight desktop application designed to simplify the creation of administrative documents using structured data, reusable templates, and office software integration.

The project starts with one essential document: the **Attestation de Travail (Employment Certificate)**. Plume aims to make document generation faster, more consistent, and easier to manage.

## Features

### Planned

- **Employee Data Management** — Store and manage employee information locally.
- **Document Generation** — Generate administrative documents from reusable templates.
- **Office Integration** — Support workflows with LibreOffice and Microsoft Office.
- **Reusable Templates** — Keep document templates separate from application logic.
- **Local Data Storage** — Use SQLite for structured employee information.
- **Privacy-Focused Design** — Keep employee data and document processing local.

## Getting Started

Plume is currently in its initial development stage. Installation instructions and usage documentation will be added as the project develops.

### Prerequisites

- Python
- PyQt6
- LibreOffice and/or Microsoft Office

SQLite is included with standard Python distributions and does not normally require a separate installation.

Plume aims to provide a straightforward, reliable, and maintainable solution for generating administrative documents without unnecessary complexity.

The project prioritizes simplicity, local data handling, reusable templates, and compatibility with common office software.
